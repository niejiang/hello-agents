# 任务 2: 关键语法与API

目标：掌握 asyncio 的核心语法和常用 API，如 async/await 关键字、asyncio.run()、asyncio.gather()、asyncio.create_task() 等的使用方法。检索方向：Python asyncio async await gather create_task 教程。

关键发现与深度解析：
1. 核心语法基石：async/await 与协程状态机原理。async def 定义协程，await 挂起并让出控制权。从 Python 3.5 引入替代 yield from，本质是编译器层面的状态机转换，将阻塞 I/O 转化为非阻塞事件循环调度。
2. 任务编排演进：从 gather 到 TaskGroup 的结构化并发。create_task 立即调度，gather 并发收集结果。Python 3.11+ 引入 TaskGroup，解决 gather 异常处理缺陷，实现类似 Go errgroup 的结构化并发，确保子任务生命周期安全。
3. 入口管理：asyncio.run() 的封装与隔离。作为 Python 3.7+ 推荐的顶层入口，自动创建/关闭事件循环，避免全局状态污染。工程实践中需注意在 Jupyter 等已有循环环境中的冲突问题。
4. 异步同步原语与流控：Lock/Queue/wait_for。异步锁用于协调协程执行顺序而非保护 CPU 临界区；wait_for 实现超时控制；Queue 构建生产者-消费者模型。核心原则是仅在 await 点发生上下文切换。
