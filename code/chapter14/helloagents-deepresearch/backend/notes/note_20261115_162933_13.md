# 任务 4: 最佳实践与避坑

目标：总结 asyncio 开发中的常见陷阱（如阻塞事件循环）及最佳实践（如使用 run_in_executor 处理 CPU 密集型或阻塞 I/O，异常处理机制）。

关键发现与避坑指南：
1. 核心原则：严禁阻塞事件循环。asyncio 是单线程协作式多任务，同步阻塞操作会导致整个事件循环停滞。工程实践中必须使用原生异步库。
2. 破局之道：利用 run_in_executor 桥接同步与异步。I/O 密集型用 ThreadPoolExecutor，CPU 密集型用 ProcessPoolExecutor 绕过 GIL。
3. 异常管理：使用 asyncio.gather(return_exceptions=True) 收集异常，避免单个任务失败导致并发组中断。
4. 架构陷阱：避免在 run_in_executor 的同步函数中反向调用异步逻辑，防止 RuntimeError 或死锁，严格划分同步异步边界。
